# 전사가 아닌 지식 정리

[English](practice.md) | **한국어**

[START](START.ko.md), 채운 사용자 프로필과 오늘 목표를 사용한다. 명령/권한/요청/CAS/중단은
[운영 workflow](../workflows/AGENT-WORKFLOW.ko.md)가 정본이다. 이 가이드는 의미 있는 지식
작업을 안내한다. CLI는 준비된 글을 저장하며 의미 판단을 대신하지 않는다.

## 요청 이해

실제 권한에서 답변만/명시 저장/정당한 연결/수정/사용자 활성 트리거를 구분한다. 일반 대화를
수집으로 바꾸지 않는다. 빠진 범위나 실제 갈림길만 확인하고 이미 허가한 매 명령을 되묻지
않는다. 선호는 깊이/주제/정리를 바꾸지만 원문 원칙은 바꾸지 않는다. 강제 분류/링크 수는 없다.

## 원문 다음 해석

허가한 파일은 준비 노트 전에 그 파일 그대로 capture한다. BOM/CRLF까지 캡처와 원문 바이트/
해시를 비교한다. 복사/붙여넣기로 재구성하거나 요약을 원문으로 저장하지 않는다. 채팅은 노출된
정확한 텍스트를 허용된 파일로 남기고 호스트 export/정규화 한계를 밝힌다. 접근 못한 원채널
바이트까지 보존했다고 주장하지 않는다. 수정 자료에도 새 source ID를 쓰고 준비 글은 번들 밖에
둔다. 실제 producer를 선언하며 사람 검토를 꾸미지 않는다. 불확실한 생각도 가치 있게 남길 수 있다.

허용된 원문 전체를 읽고 무엇을 이해하려는지, 왜 중요한지, 어떤 예/긴장이 의미를 지탱하고
어디까지 적용되는지 살핀다. 문장 재배열/기계적 추출/일반 조언 대신 유용한 지식 본문을 쓴다.
모든 문장을 확정 규칙으로 만들지 않는다. 출처 주장, 사용자 생각/경험, 에이전트 해석,
미검증 추론/질문을 구분한다. 책/저자의 말/강해진 확신/심리 진단/사용자 선호를 만들지 않는다.
[본문 틀](note-body.ko.md)은 유연한 모양이지 모든 칸을 강제하는 양식이 아니다. 자연스럽게
사용자가 결과를 읽고 고칠 수 있게 한다.

## 근거 있는 연결

연결 전에 현재 제목/본문 단어의 recall, 허가된 이력의 search, 정확한 show와 허가한 원문으로
기존 지식을 찾는다. 대상을 읽고 어떤 관계가 왜 도움이 되는지 근거로 설명한다. 같은 단어/
분류나 “둘 다 독서”만으로는 부족하다. 무관/못 찾음이면 범위/한계와 함께 알리고 독립 노트로
남긴다. 검색 실패로 전역 부재를 단정하지 않는다. recall은 annotation/raw 원문 검색이나
의미 검색이 아니다.
recall은 선택 번들의 현재 인덱스 노트를 모두 읽고 개념 --scope 옵션이 없다. 허용 밖 내용을
읽게 된다면 recall이나 전체 search/list/check를 호출하지 않는다. 허가한 정확한 show 또는
범위 있는 context/graph/health를 쓰고 조회 한계를 알린다.

일반 Markdown 설명과 정당한 정확한 리비전 링크를 우선한다. typed relation은 선택이며
[실제 스키마](../docs/graph.ko.md)를 따른다. 리비전 없는 ID는 현재 포인터이고 pin은 과거
근거이지 자동 갱신이 아니다. edge/역방향 쓰기/출처 품질 승계를 강제하지 않는다.

## 저장과 수정

기존 capture/curate/선택 annotate와 저장한 요청/CAS 계약을 쓴다. curate에 관련 source ID와
전체 본문/원하는 상태/annotations를 명시하며 이전 메타데이터/verified를 암묵 승계하지 않는다.
같은 지식의 수정에는 ID를 재사용하되 무관한 내용을 덮어쓰지 않는다. 먼저 현재를 읽고 과거
파일을 보존하며 새 결과를 비교한다. 바뀐 의미와 남은 의미를 함께 설명하고 과거 리비전의
역링크를 수정하지 않는다. 원문/이전/관련 경로는 준비 파일이 아닌 **최종 리비전** 기준이다.
[본문 틀](note-body.ko.md)을 참고한다. 새 해석이 자동 검토되거나 journal/복구가 생기지 않는다.

요청한 쓰기 뒤에는 [navigation](navigation.ko.md)에서 허가한 탐색만 갱신한다. 현재/원문/이전
링크를 읽어 확인하고 긴 기술 출력 대신 의미 변화와 불확실성을 알린다. 명령 ID/재시도는
에이전트가 맡는다. context 인계는 선택이며 검색 가능한 지식 본문을 대신하지 않는다.
recovery_required면 멈추고 새 키로 우회하지 않는다.

## 새 세션 재사용

제공된 bootstrap/profile/bundle을 쓰고 예전 채팅/개인 기억에 기대지 않는다. 관리 index에서
현재를 확인하고 역사 질문은 과거 리비전을 의도적으로 읽는다. 정확한 근거와 함께 이 사용자의
새 질문에 답하며 과거 생각이 어떻게 영향을 주는지, 그때/지금/출처/해석을 구분한다. 자료가
없거나 부분적이면 기억을 꾸미거나 일반 조언으로 메우지 않는다. 답변만 요청에는 질문 capture,
새 노트, context annotate나 탐색 갱신을 하지 않는다. graph/health는 구조 진단이지 사실 검사가
아니다. 명시적 검색 평가는 이후 도움을 주지만 의미 품질의 사람 평가를 대신하지 않는다.
