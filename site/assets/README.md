# Vision artwork

`second-brain-vision-v01.webp` is an optimized copy of the original AI-generated
artwork supplied for Local Second Brain on 28 October 2026. It illustrates the
Second Brain we are building toward, rather than a current product screen.

The full 1672 × 941 composition is preserved. Only WebP encoding and metadata
removal were applied with ImageMagick; no cropping, compositing or new generation.

# Agent report scenario

`agent-report-v2-ko.mp4`, `agent-report-v2-en.mp4` and their `.jpg` posters are the
captioned, silent 37.5-second scenario in which an agent the user authorizes searches and
reads saved notes with the CLI and prepares a report draft. They are rendered from
`scripts/agent-outcome-video/scene.html` with fictional materials; see that folder's README
to reproduce them. The earlier `report-scenario-v1-*` files are kept unchanged for reference.
