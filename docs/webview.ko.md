# 선택해서 여는 로컬 지식 모니터

[English](webview.md)

설치된 환경에서 살펴볼 Local Second Brain CLI 번들 하나를 명시한다.

```sh
second-brain view /absolute/path/to/bundle --port 8765
```

출력된 `http://127.0.0.1:8765/`를 브라우저로 연다. `--port 0`은 사용 가능한 포트를
선택한다. 종료는 Ctrl-C다. 브라우저를 자동 실행하거나 프로그램을 설치하지 않는다.
일반 Obsidian vault가 아니라 기존 CLI 번들을 보여 준다. Python과 PyYAML 외의 필수
의존성, 실행 중 모델 호출이나 외부 자산 요청은 없다. 기존 명령과 저장 형식은 유지한다.

현재 제목과 본문에서 문자열을 찾고 상태, 검토 선언과 확인 기한으로 목록을 좁힌다.
원문과 과거 본문은 검색 범위에 포함되지 않는다. 실제 리비전을 나란히 읽고 본문과
메타데이터의 차이를 본다. 원문, 출처 기록과 연결된 노트까지 이동할 수 있다. 본문이
같다고 검토 이벤트라고 추정하지 않는다. 작성 주체와 검토 표시는 기록된 선언이며
신원 인증이나 사실 검증이 아니다. 사용자 원문 여부와 에이전트 해석은 기록된 내용과
출처에 근거해서만 판단한다.

자동 갱신 대신 새로 읽기를 누른다. 스캔 시각과 마지막 성공 시각을 표시하며 실패하면
기존 성공 화면과 실패 알림을 함께 남긴다. 현재 기록을 보던 중이면 갱신된 index 선택을
따라가고, 의도적으로 연 과거 기록은 유지한다. 현재 선택과 내용의 사실성은 별개다.
기한이 없거나 판정할 수 없으면 최신이라고 표시하지 않는다.

## 데이터 범위와 안전성

서버는 `127.0.0.1`에만 바인딩한다. 출력된 정확한 Host와 같은 Origin만 허용하고
교차 사이트 요청, 허용적인 CORS와 쓰기 메서드는 지원하지 않는다. `localhost` 대신
출력된 숫자 주소를 쓴다. 공개 origin이나 네트워크 바인딩 옵션은 없다. v01의 Portal과
역방향 프록시 전달은 검증하지 않았다. 이를 위해 포트를 공개하거나 보안 헤더를
우회하지 않는다. 자산 URL은 상대 경로이지만 이것만으로 프록시 호환을 보장하지 않는다.
사용하지 않을 때 종료한다. 같은 컴퓨터의 다른 프로그램에 대한 인증 경계는 아니다.

고정 UI 파일과 스냅샷 API만 제공하며 임의 파일을 여는 endpoint는 없다. 저장된
Markdown, HTML, script, URL과 원문은 텍스트로만 표시한다. 탐색 버튼은 읽어 온
리비전만 연다. 출처 ID와 resource가 같은 `sources/ID/content.raw`를 가리킬 때만
보존물을 읽는다. URL, resource만 있는 선언, 잘못된 연결에는 원문 경로를 추정하지
않고 미지원 또는 미확인 상태를 남긴다. 외부 URL을 가져오지 않는다.

기존 Store의 descriptor 기반 읽기를 사용하며 잠금과 쓰기를 하지 않는다. 루트,
선택한 개념 디렉터리나 읽는 경로의 symlink는 거부한다. lock, cache, index, 영수증이나
`.obsidian` 파일을 만들지 않는다. 응답 전에 읽은 파일과 index를 재확인해 관측된
변경을 탐지하지만 다중 파일의 원자적 스냅샷은 아니다. 다른 작성자가 자료를 바꾸면
멈추거나 다시 읽는다. 루트 교체 후에는 웹뷰를 재실행한다.

스캔 한도는 현재 개념 100개, 리비전 256개, 출처 128개, 선택한 디렉터리당 항목 512개,
파일당 512 KiB, 전체 입력 8 MiB, 응답 12 MiB다. YAML alias를 복사하기 전 메타데이터
변환을 방문 4096회와 깊이 16으로 제한한다. 읽기 또는 출력 한도를 넘으면 갱신을
실패로 알리며 0으로 바꾸지 않는다. 누락된 현재 파일과 연결 표시 한도는 부분 또는
미확인 상태로 남긴다. index에 없는 다른 개념과 무관한 디렉터리는 탐색하지 않는다.
연결은 [graph 파서의 지원 범위](graph.ko.md)를 따르므로 표시가 없다고 의미상
관계가 없음을 입증하지 않는다. 읽기 범위 밖의 경로를 열어 존재 여부를 판정하지 않는다.
UTF-8이 아닌 원문은 해석을 꾸미지 않고 표시 가능 여부와 해시 정보만 보여 준다.

## 검증

경계와 읽기 전용 회귀 검사는 `python -m unittest discover -s tests -p test_webview.py -v`다.
편집기, 수집, 이전이나 별도 검토 이벤트 저장소는 추가하지 않는다.
[화면 원칙](../DESIGN.md)을 따른다. 브라우저 검증은 공개 합성 자료와 격리 프로필로
수행하며 HTTP 응답 성공만으로 실제 화면이나 사용성 검증을 주장하지 않는다.
