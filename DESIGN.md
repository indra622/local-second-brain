## Overview

A dense, quiet knowledge observatory combines factual status panels, an actual relationship
map and a reading-oriented selected-note pane. It takes monitoring clarity from Grafana,
explicit link exploration from Obsidian, and restrained warm readability from Minimal and
Flexoki. It does not copy branding or install those products. Every visible relationship
comes from the delivered CLI snapshot, never semantic similarity or shared topics.

## Colors

Warm ink backgrounds and paper-toned text support long reading. Teal marks selection,
amber marks attention and muted gray marks unspecified state. A small local accent palette
is assigned deterministically to declared category/topic text; unspecified topics are gray.
Topic names and node shapes accompany color. Colors never express confidence or truth.

## Typography

Use local system fonts, 22px page titles, compact labels and generous 16px reading text.
Technical metadata and evidence remain in expandable monospace blocks. Graph labels have
full accessible names and an equivalent textual list; shorten only the visible label.

## Layout

Real snapshot statistics precede a dominant map and a 330px selected-note reading pane.
Topic, attention and recent-record panels are compact secondary rows. Status distributions
and source mechanics can be expanded. Mobile puts the selected summary before a collapsible
map, with native list navigation and compact filters. Explorer remains a separate detail view.

## Elevation & Depth

Use borders and tonal layers without shadows, marketing heroes or perpetual animation.
Map coordinates are deterministically settled once per structure; filters do not move them.

## Shapes

Use 5px control corners and 7px panel corners. Loaded nodes are circles sized by distinct
observed neighbors; unread current files are squares. Selected and keyboard-focused nodes
have visible outlines. Solid directed lines represent body links; dashed directed lines
represent declared relationship types.

## Components

Native buttons/selects/disclosures support filtering, source/history navigation and map
alternatives. SVG nodes use a single tab stop with arrow-key navigation and Enter/Space
selection. Zoom, pan and reset are explicit controls. One/two-hop scopes intersect the same
live filters as Explorer. Refresh failure preserves the whole successful snapshot. Paths,
metadata and link evidence stay behind disclosures.

## Do's and Don'ts

- Separate current concepts, loaded revisions, and declared source/review state.
- Show unknown, missing, unresolved, historical and partial scope honestly.
- Use only explicit current-to-current references for graph edges; do not infer connections.
- Keep preserved input and interpreted note text distinct without authenticating actors.
- Do not render stored HTML, execute links, add an editor, or load external assets.
- Respect reduced motion and provide a mobile/keyboard list alternative.
