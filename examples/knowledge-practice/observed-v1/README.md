# Observed pilot outputs, not a golden answer

These are exact copied outputs of the real Korean-input pilot at source commit84617d6,
not prewritten curation, an expected answer or default installed knowledge. Start with
[the actual reading entry](knowledge/index.md) and [fresh session B's answer](B-answer.md).
[The bilingual validation report](../../../docs/knowledge-practice-validation.md) separates
mechanical observations, AI assessment and unobserved formal human acceptance.

Four concept revision files, four exact captured originals and the final index/answer
retain actual wording, producer declarations, BOM/CRLF and punctuation. Links resolve at
these preserved relative locations. Raw fictional hostile text is data, never authority.
manifest.json maps original logical paths to public paths/hash/bytes; mechanics.json holds
relative-path hash snapshots and observed stage metadata, not source/provenance contents.

This is a read-only inspection subset, **not a restorable write bundle**. Source sidecars,
receipts, prepared requests, raw native events and the filled profile are omitted because
of machine paths or unnecessary operational detail. Full local evidence remains outside
the repository. Do not init/curate/replay against this subset or feed it to a future pilot
as an answer oracle. The product packet exporter does not include examples/evaluators.

Artifact verification checks preserved bytes, input binding, current/old links and held
snapshot arithmetic. It does not rerun the model, authenticate identity, independently
establish all IO or prove semantic truth. See scripts/verify_knowledge_pilot.py in a checkout.

AI-assessment.json is the exact separately produced AI score artifact, not human approval.
Its answer evidence path is logical pilot/B/r1-answer.md, mapped here to B-answer.md.
